The best way to learn a topic is to write about it as if you were teaching
it. This is the idea behind "learning in public", and it works.

## Why it works

When you write to teach, you cannot hide. You must explain every step. The
gaps in your understanding become visible, and that is exactly where the
learning happens.

- You find the parts you do not understand.
- You find the parts you assumed but never checked.
- You find the words you were missing.

## The method

1. Pick a topic you want to learn.
2. Write a short post about it.
3. Publish it, even if it is rough.
4. Let people correct you.
5. Revise.

## A worked example

Suppose you want to learn how a hash table works. You write:

```text
A hash table maps keys to values.
It uses a hash function to find a bucket.
Collisions are handled by chaining or probing.
```

Writing that forces you to answer: what is a bucket? What is a collision?
What is the difference between chaining and probing? If you cannot answer,
you know what to study next.

## The tools

- A blog, like this one.
- A notebook.
- A willingness to be wrong.

## The payoff

> You do not really understand a thing until you can explain it to someone
> else. Writing is the fastest way to find out whether you can.

## A checklist

- [x] Write the post.
- [x] Publish it.
- [ ] Ask for feedback.
- [ ] Fix the mistakes.
- [ ] Write the next one.

Learning in public is a habit. Like all habits, it gets easier the more you
do it.
